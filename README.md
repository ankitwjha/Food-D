# Food-D

A full-stack food delivery web application built using React, Vite, Node.js, Express, and MongoDB.

## Features

- **Frontend**: Customer portal for browsing food items, adding to cart, placing orders, and tracking order status.
- **Admin Panel**: Dashboard for managing food menu items and tracking orders.
- **Backend**: REST API handling users, food catalog, cart, and stripe payments.
- **Database**: MongoDB for storage.
